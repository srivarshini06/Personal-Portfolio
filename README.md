# Personal Portfolio

A modern, responsive personal portfolio website built with plain HTML, Tailwind CSS, and vanilla JavaScript.

## Features
- Dark theme with a smooth light/dark toggle
- Responsive hero, about, projects, and contact sections
- Smooth scrolling navigation
- Animated fade-in sections and hover interactions
- Subtle gradient backgrounds and glowing cursor effect

## Run locally
1. Open `index.html` directly in a browser, or use a local server.
2. If using Vite, run:
   ```bash
   npm install
   npm run dev:frontend
   ```

## Notes
This portfolio is intentionally built without React or front-end frameworks.
